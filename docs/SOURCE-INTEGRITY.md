# Source integrity

The repository contains two representations of the application core:

- `app/aag_canon.py` — readable public source for review and development.
- `app/aag_canon.py.gz.b64` — canonical compressed payload generated byte-for-byte from the camera-tested v1.1.0 production source.

`install.sh` materializes the canonical payload, validates it with `python3 -m py_compile`, and installs that exact version. This avoids accidental drift between the tested artifact and a public packaging edit.

The static CI test also decodes and syntax-checks the canonical payload.
